# Pruebas automatizadas — RF-07 Renombrado y estructuración de carpetas

## Alcance

- **Requisito:** RF-07 — los documentos se renombran y organizan en carpetas según los metadatos obtenidos.
- **Aplicación:** `construccion-escritorio`.
- **Componente:** `src/core/file_structurer.py` (`FileStructurer.RenameAndStructure`).
- **Requisitos no funcionales relacionados:** RNF-01 (tiempo de procesamiento Edge). El límite de 2 s por folio no se atribuye a este módulo aislado; la prueba de carga observa un lote de 250 estructuraciones y aplica un umbral de regresión amplio.
- **Aislamiento:** las rutas se crean dentro de directorios temporales; no se modifican documentos del usuario.

## Casos de prueba

| ID | Tipo de prueba | Funcionalidad verificada | Criterio de verificación | Automatización |
|---|---|---|---|---|
| CP-RF07-01 | Unitaria (de componente) | Limpieza de valores de ruta | Se eliminan caracteres no válidos y se rechazan valores que quedan vacíos. | `test_unitaria_limpia_caracteres_invalidos_y_valores_vacios` |
| CP-RF07-02 | Integración | Creación de jerarquía | Se crean las carpetas esperadas y la función devuelve el destino sin crear todavía el PDF. | `test_integracion_crea_la_jerarquia_y_no_escribe_el_pdf` |
| CP-RF07-03 | Funcional | Renombrado desde metadatos | El nombre del archivo y la jerarquía conservan el orden de metadatos y el separador indicado. | `test_funcional_construye_nombre_y_carpetas_desde_metadatos` |
| CP-RF07-04 | Rendimiento/estrés | Lote de documentos | 250 rutas distintas se estructuran en menos de 10 s. | `test_rendimiento_estructura_doscientos_cincuenta_folios` |
| CP-RF07-05 | Aceptación automatizada | Metadatos con separadores de ruta | Un valor con `../` queda sanitizado y el destino permanece bajo la carpeta base. | `test_aceptacion_impide_que_metadatos_salgan_de_la_carpeta_base` |

## Ejecución y resultado

```bash
python -m unittest discover -s tests -p 'test_rf07*.py' -v
```

GitHub Actions ejecuta el mismo comando en `.github/workflows/pruebas-rf-07.yml`. La suite es headless y entrega como evidencia la salida del trabajo; no genera captura de pantalla porque no hay una interfaz gráfica bajo prueba.

**Resultado local:** 5/5 casos aprobados con Python 3.14.6; duración total observada: 0,013 s.

## Límites

La prueba cubre la estructuración de rutas en el sistema de archivos temporal. No incluye el OCR que produce los metadatos, la copia/cifrado del contenido ni validación manual del nombre desde la interfaz.
