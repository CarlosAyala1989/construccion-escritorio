# Pruebas automatizadas — RF-08 Derivación a bandeja de pendientes

## Alcance

- **Requisito:** RF-08 — los documentos con problemas de lectura, extracción o validación se envían a una bandeja para revisión manual.
- **Aplicación:** `construccion-escritorio`.
- **Componente:** `src/core/pending_tray.py` (`PendingTray.HandleOCRFailure`).
- **Requisitos no funcionales relacionados:** RNF-07 (tolerancia a fallos y recuperabilidad). La prueba verifica que el fallo de movimiento se devuelve y registra; no mide recuperación de hardware.
- **Aislamiento:** usa archivos temporales y no modifica datos de trabajo.

## Casos de prueba

| ID | Tipo de prueba | Funcionalidad verificada | Criterio de verificación | Automatización |
|---|---|---|---|---|
| CP-RF08-01 | Unitaria (de componente) | Fallo al derivar un origen inexistente | Devuelve `None`, registra el error y no oculta el resultado al llamador. | `test_unitaria_registra_y_devuelve_fallo_si_no_existe_el_origen` |
| CP-RF08-02 | Integración | Movimiento y conservación de contenido | El origen desaparece, el destino aparece y los bytes se conservan. | `test_integracion_mueve_el_archivo_y_conserva_su_contenido` |
| CP-RF08-03 | Funcional | Creación y uso de la bandeja | Se crea la ruta de pendientes y se devuelve el nombre del documento derivado. | `test_funcional_crea_la_bandeja_y_devuelve_la_ruta_resultante` |
| CP-RF08-04 | Rendimiento/estrés | Lote con nombres repetidos | 120 orígenes de igual nombre se derivan a destinos únicos en menos de 10 s. | `test_rendimiento_deriva_ciento_veinte_colisiones_sin_perder_archivos` |
| CP-RF08-05 | Aceptación automatizada | Conservación ante colisión | El folio previo permanece intacto y el nuevo se guarda como `_v2`. | `test_aceptacion_conserva_el_archivo_existente_y_deriva_a_v2` |

## Ejecución y resultado

```bash
python -m unittest discover -s tests -p 'test_rf08*.py' -v
```

GitHub Actions ejecuta el mismo comando en `.github/workflows/pruebas-rf-08.yml`. La salida de Actions es la evidencia automatizada; el caso se ejecuta sin interfaz gráfica, por lo que no se genera captura de pantalla.

**Resultado local:** 5/5 casos aprobados con Python 3.14.6; duración total observada: 0,032 s.

## Límites

La suite prueba el movimiento local y las colisiones. No simula la detección OCR ni valida la revisión humana desde la interfaz de pendientes.
